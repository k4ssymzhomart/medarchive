# Дизайн система v3 (источник правды)

Лендинг (`frontend/src/landing` и shadcn шаблоны в `frontend/src/components`) задаёт язык дизайна, продукт `/app` переодевается под него постепенно. Токены вынесены в `frontend/tailwind.config.js` и CSS переменные в `frontend/src/styles/index.css` (включая shadcn совместимые токены). Менять стиль через токены, не хардкодить цвета.

## Эталон дизайна
- Эталон стиля для новых секций — floating-icons hero (`components/ui/floating-icons-hero-section.tsx`) и bento features (`components/blocks/features-8.tsx`). Светлая база, белые карточки со скруглением и мягкой тенью, градиентный текст, фиолетовый акцент, плавающие элементы.

## Цвет (один фирменный акцент, три тона)
- Акцент: `#6D5EF6`, светлее `#9A8CFF`, темнее `#4B3FD6`. shadcn `primary` замаплен на акцент.
- Нейтрали: ink `#0A0A0B`, surface dark `#121214`, граница на тёмном `#26262B`, paper `#FFFFFF`, мягкий фон `#F4F5F8`, вторичный текст `#6B7280`, линия `#E5E5E5`.
- Градиенты ТОЛЬКО из акцента и нейтралей: радиальное свечение, диагональ акцента для CTA. Никаких пёстрых многоцветных градиентов.

## Геометрия
- Пилюля (full) для навигации, кнопок и инпутов. Карточки и панели 20 24px (`rounded-card`, `rounded-panel`), shadcn карточки `rounded-lg`.
- В продукте пока сохраняются острые радиусы (`rounded-sm` 2px); переезжают на v3 постепенно.
- Сетка контента max width около 1200px (`max-w-content`). Ритм отступов варьируем намеренно: плотная секция, затем дышащая (`py-16` против `py-40`), не одинаковый `py` везде.

## Типографика
- Дисплей и текст: Space Grotesk. Моно для надзаголовков (eyebrow): JetBrains Mono (`.eyebrow`).
- Контраст масштаба: один доминирующий элемент на сцену (гигантская реальная цифра против мелких подписей).

## Моушн (по гайду скролл-моушна; принципы ниже, токены в lib/motion.ts)
- Токены моушна в `frontend/src/lib/motion.ts`: кривые `ease` (ease-out для входов, ease-in для выходов), пружины `spring`, `scrubSpring`, семья `reveals` по интенту (statement/evidence/sequence/lead/sub). Никаких inline магических чисел.
- Плавный скролл: Lenis (`landing/SmoothScroll.tsx`), синхронизирован с Framer одним RAF.
- Пять дисциплин: сдержанность (по умолчанию покой, ~одно осмысленное движение на вьюпорт), ритм, интенция (каждое движение отвечает «зачем именно это»), один подписной момент, движение со смыслом.
- Подписной момент страницы — конвейер `landing/Pipeline.tsx` (pinned scrub: извлечение, нормализация, проверка). На него тратим бюджет моушна, остальное тише.
- Анимируем ТОЛЬКО `transform` и `opacity` (компоновка на GPU, 60fps). Не анимируем width/height/top/box-shadow.
- ОБЯЗАТЕЛЬНО уважать `prefers-reduced-motion`: `MotionConfig reducedMotion="user"`, Lenis не монтируется, scrubbed секции дают статичную раскладку. Lenis выключен и на мобайл (`<768px`), нативная инерция лучше. Страница обязана рассказывать историю и при выключенном моушне.
- Счётчики считают реальные цифры один раз при появлении, expo-out, без оверщута.

## Структура лендинга (beat sheet)
Hero (claim) → Возможности (features) → Проблема (tension, тёмная) → Конвейер (подписной момент) → лента (velocity marquee) → Доказательства (реальные счётчики) → Заявление (пауза) → CTA (магнитная кнопка) → Футер.
