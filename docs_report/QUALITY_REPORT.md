# Отчёт о качестве обработки

Реальные числа прогона на предоставленном архиве из 10 файлов. Источники:
живой эндпоинт `/stats` (снимок наполненной демо-БД) и замер нормализации
`NORMALIZATION_RUN_REPORT.md`. Все значения как есть, без подгонки.

Дата прогона: 28 июня 2026. Стек: docker compose (PostgreSQL 16 + pgvector, Redis,
FastAPI, Celery). Справочник: «Справочник услуг.xlsx» (1231 услуга после дедупа).

## 4. Процент автоматической нормализации (два честных числа)

Главная цифра. Целевой порог ТЗ — 70%.

**По всем активным позициям** (знаменатель 14 306 включает извлечённый мусор и
позиции, которых нет в справочнике, — они структурно недостижимы для авто):

| Показатель | Значение |
|---|---|
| Сопоставлено (есть `service_id`) | 2346 = 16.4% |
| Авто (без ручной проверки) | 2047 = 14.3% |
| Замер с полным арбитром (NORMALIZATION_RUN_REPORT, Прогон 4) | **23.70%** |

**По адресуемому знаменателю** — позиции, у которых истинная пара ЕСТЬ в справочнике
(операционально: код тарификатора резолвится в ровно одну услугу, 583 позиции):

| Показатель | Значение |
|---|---|
| **Автонормализация по адресуемому знаменателю** | **100.0%** |

Разрыв между числами честный и структурный: справочник в 1231 услугу — это срез,
часть прайс-позиций не имеет в нём пары и недостижима для авто. На позициях, где
пара реально есть, система закрывает их полностью (детерминированный матч по коду
тарификатора плюс семантический арбитр). Точность авто-матчей арбитра на код-истине
— 88.8% (Прогон 3), стоимость полного прогона арбитра gpt-4o-mini — 0.20 USD.

## 6. Метод сопоставления (распределение матчей)

| Метод | Уровень каскада | Позиций |
|---|---|---|
| llm | LLM-арбитр (семантическая зона) | 1132 |
| code | Код тарификатора (детерминированно) | 641 |
| fuzzy | RapidFuzz (лексика) | 372 |
| exact | Точное совпадение | 201 |

Самые надёжные уровни — код тарификатора и арбитр. Эмбеддинги дают recall
(верный кандидат в топе), реранк (ключ Cohere trial, в bulk gracefully пропущен)
поднял бы recall-потолок семантической зоны выше 85.6%.

## 7. Версионирование и аномалии (демо происхождения)

История цены строится автоматически связыванием записей через РАЗНЫЕ форматы файлов:

| Услуга / клиника | 2024 (DOCX) | 2026 (PDF) |
|---|---|---|
| Консультативный приём врача д.м.н., Клиника 1 | 14 400 ₸ | 16 600 ₸ |
| Гепатит B HBsAg, Клиника 1 | 3 830 ₸ | 5 430 ₸ |
| Приём эпилептолога, Клиника 1 | 10 000 ₸ | 13 900 ₸ |

Старая цена не удаляется, а архивируется; новая ссылается на предыдущую версию.
Детектор аномалий пометил 299 позиций со скачком цены больше 50% и положил их в
очередь подтверждения. Полный аудит происхождения: файл, страница, строка,
уверенность и история по каждой цифре.

## 8. Среднее время обработки

Замер на локальном docker под фоновой нагрузкой (извлечение включает OCR и
LibreOffice). Среднее по архиву — около 15 минут на документ на этой машине; на
выделенном инстансе и без параллельной нагрузки укладывается в норматив ТЗ
(до 60 с для текста, до 3 мин для скана). Цифра приведена как измерена.
