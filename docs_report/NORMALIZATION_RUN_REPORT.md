# Отчёт о прогоне нормализации

Дата прогона: 27 июня 2026. Ветка: feat/normalization-unblock.
Стек: docker compose (Postgres 16 + pgvector, Redis, FastAPI, Celery).
Ключи AI на прогоне: отсутствуют (путь code + exact + fuzzy, без эмбеддингов и реранкера).

## Что подтверждено

| Задача | Результат |
|---|---|
| A. Маппинг загрузчика | `seed-reference "Справочник услуг.xlsx"` загрузил **1231 услугу** (1281 строк, дедуп по паре имя + код тарификатора). У записей заполнены category (специальность) и icd_code (код тарификатора). Блокер снят. |
| B. Level 0 матч по коду | Работает. Одиночный код тарификатора даёт уверенность 0.98, неоднозначный 0.95. **1489 позиций** сопоставлены методом `code` (наибольшая доля матчей). Клиника 3: **74 позиции** по коду. |
| C. Снят фильтр по категории | Семантика и лексика больше не отсекают кандидата по неравенству категории (специальность справочника против раздела прайса). |
| E1. .xls (Клиника 7) | LibreOffice headless в образе сконвертировал .xls: **2864 позиции**, читаемые русские названия (Иммуноглобулин М, Комплемент С3). Локально без LibreOffice путь даёт 0, в Docker работает. |
| E2. Сканы (Клиника 2 2026, Клиника 3) | Встроенный текстовый слой читаем (детектор не пометил как битый), извлечены русские названия без артефактов. ПереOCR на этих файлах не потребовался. |
| Версионирование (демо) | Услуги, сопоставленные в обоих прайсах Клиники 1 (2024 DOCX и 2026 PDF), строят историю цен: Гепатит B HBsAg 3830 → 5430, Прием эпилептолога 10000 → 13900, IgG общий 2950 → 4180. |

## Метрики прогона (GET /stats)

- Документов: 10, все обработаны.
- Позиций всего: 18 435. Активных (после версионирования): 16 748.
- Сопоставлено методами code/exact/fuzzy (всего по базе): **2983** позиции
  (code 1489, fuzzy 1160, exact 334).
- Автонормализация активных позиций (метрика /stats): **7.7%**.
- Доля когда либо автосопоставленных позиций: **16.2%**.
- Очередь needs_review: 15 555. unmatched: 5.

Разница между 7.7% и 16.2% объясняется версионированием: сопоставленные
позиции схлопываются между годами (старая версия архивируется), несопоставленные
остаются активными. То есть активная метрика занижает реальное качество матча.

## Главный вывод: порог 70% упирается в эмбеддинги, а не в код

Цель ТЗ 70% автоматча на этом прогоне не достигнута, и причина структурная, а не в правках A/B/C.

Распределение позиций по верхнему лексическому баллу (RapidFuzz) против справочника:

| Полоса | Доля | Что это |
|---|---|---|
| code + exact | 11.4% | детерминированный матч, авто |
| fuzzy ≥ 0.85 | 5.9% | лексический авто |
| 0.60 – 0.85 | 26.9% | пограничная зона (адресуется LLM арбитром) |
| **0.40 – 0.60** | **52.7%** | **смысловое совпадение без лексического (нужны эмбеддинги)** |
| < 0.40 | 3.1% | мусор извлечения или нет в справочнике |

Больше половины позиций (52.7%) лежат в полосе 0.40 – 0.60: смысл совпадает,
а слова разные («Консультативный прием врача акушера» против справочного
«Прием акушер-гинеколога»). Эти случаи закрывают только эмбеддинги
(семантический кандидатогенератор, уровень 3 каскада). Даже идеальный LLM арбитр
по всей пограничной полосе даёт потолок ~44%.

Архитектура (раздел 5.1) ставит эмбеддинги OpenAI text-embedding-3-large
основным кандидатогенератором. На прогоне доступен только ключ Anthropic
(LLM арбитр), ключа эмбеддингов (OpenAI или Voyage) нет, поэтому уровень 3
выключен, и матч держится на коде и лексике.

## Что даст 70%

1. **Ключ эмбеддингов** (OpenAI text-embedding-3-large, dim 3072, или Voyage).
   Это основной рычаг: закрывает полосу 0.40 – 0.60. Прогнать
   `seed-reference` заново (досчитает Service.embedding), затем `ingest docs`.
2. Закалка извлечения (issue склейки многострочных названий): чище
   service_name_raw поднимает и лексику, и эмбеддинги, и убирает мусор из знаменателя.
3. Тюнинг порога `MATCH_HIGH_THRESHOLD` 0.85 → 0.80 (раздел Task D): малый эффект
   (несколько процентов), без эмбеддингов 70% не даёт.

## Воспроизведение

```bash
cp .env.example .env            # для 70% впишите OPENAI_API_KEY (эмбеддинги)
docker compose up --build -d
docker compose exec backend python -m app.cli seed-reference "Справочник услуг.xlsx"
docker compose exec backend python -m app.cli ingest docs
# метрики: GET http://localhost:8000/stats
```
